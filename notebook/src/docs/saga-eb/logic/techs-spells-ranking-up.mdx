# ランクアップの仕組み
<Box>
  技・術は使用回数が一定値に到達するとランクアップし、性能が変化します。

  最大ランクは技・術によって異なり、ランクアップに必要な使用回数はそれぞれの技・術のランクごとに設定されています。技・術ごとの使用回数はブラッド技も含め、味方キャラクターごとに管理されます。味方キャラクター、技・術によらず、使用回数の初期値は0です。

  技・術ごとに設定されている最大ランク、ランクアップ必要回数、性能変化については <Link to={'/saga-eb/data/techs-spells-ranking-up/'}>データ ＞ 技・術のランクアップ</Link> を参照してください。

  ランクアップは以下2段階の判定において条件を満たすと発生します。

  <Box sx={{ ml: 1, my: 3 }}>
    ## 使用回数加算判定
    使用回数加算判定は以下のタイミングで行われます。
    - 技・術の発動前

    プロテクト技、ひらめき、オーバードライブ、独壇場によって1ターンに複数回行動する場合は都度判定されます。

    以下の条件を満たすと直後に発動する技・術の使用回数が加算されます。
    - 行動キャラクターが混乱状態でない

    ## ランクアップ判定
    ランクアップ判定は以下のタイミングで行われます。
    - 使用回数の加算後

    下式を満たすとランクアップが発生します。

    <StyledMathBox className='katex-box'>
      <BlockMath math='\small\hspace{0.5em}\text{使用回数}_{next}\geq\text{ランクアップ必要回数}_{n+1}\hspace{0.5em}'/>
    </StyledMathBox>

    ここで、使用回数<InlineMath math={'\\small _{next}'}/>は使用回数加算後の使用回数、<InlineMath math={'\\small n'}/>は現在ランク、ランクアップ必要回数<InlineMath math={'\\small _{n+1}'}/> は次ランクへのランクアップに必要な使用回数を意味します。

    ランクアップが発生すると、直後に発動する技・術にはランクアップ後の性能が適用されます。
  </Box>
</Box>

# ランクアップによるボーナス
<Box>
  ランクアップ発生直後に発動する技・術は以下相当の性能を持ちます。
  - 命中特性が必中

  本来の命中特性が対地であっても飛行敵に命中します。回避率100%の敵（海賊ビビ［2］）にも回避されません。

  ガード・カウンター不可にはなりません。状態異常付与成功率も補正されません。
</Box>

# 使用回数の加算量
<Box>
  使用回数加算後の使用回数は下式で算出されます。

  <StyledMathBox className='katex-box'>
    <BlockMath
      math='\small\hspace{0.5em}\text{使用回数}_{next}=\begin{cases}\text{使用回数}+1&\left(\text{技ランク成長ボーナスなし}\right)\\
          \text{使用回数}+2&\left(\text{技ランク成長ボーナスあり}\right)\end{cases}\hspace{0.5em}'
    />
  </StyledMathBox>

  副防具「達人の王冠」が持つ特性「技ランク成長アップ」には、使用回数の加算量が増加するボーナス（技ランク成長ボーナス）を確率で発生させる効果があります。技ランク成長アップは術に対しても同様の効果を発揮します。

  技ランク成長アップの有無と技ランク成長ボーナス発生確率の関係は下表の通りです。

  <StyledTableContainer align='center'>
    <Table stickyHeader sx={{ width: `calc(108px * 2)` }}>
      <TableHead>
        <TableRow>
          <StyledTh align='center' sx={{ width: '108px' }}>技ランク成長<br/>アップ</StyledTh>
          <StyledTh align='center' sx={{ width: '108px' }}>技ランク成長<br/>ボーナス発生確率</StyledTh>
        </TableRow>
      </TableHead>
      <TableBody>
        <StyledTr>
          <StyledTd align='center'>なし</StyledTd>
          <StyledTd align='center'>0％</StyledTd>
        </StyledTr>
        <StyledTr>
          <StyledTd align='center'>あり</StyledTd>
          <StyledTd align='center'>50％</StyledTd>
        </StyledTr>
      </TableBody>
    </Table>
  </StyledTableContainer>

  技ランク成長アップは重複しないため、達人の王冠を複数個装備しても技ランク成長ボーナス発生確率は変わりません。

  達人の王冠を装備すると50%の確率で加算量が2倍になるため、使用回数が1.5倍速く蓄積すると期待できます。
</Box>

  固有技を持つ装備品の解除などによって技・術が装備欄から消滅する場合、騎士化などによって技・術が装備不可になる場合でも使用回数は修正されません。

  統合クリアデータとは、ゲームをはじめから開始する際に引き継ぐことができる各種情報を保存している内部データです。技ランクの引き継ぎをONにすると、統合クリアデータに保存されている技・術の使用回数（統合使用回数）が参照されます。

  統合クリアデータはゲームをクリアすると更新されます。

  更新後の統合使用回数は、全ての味方キャラクターの技・術ごとに下式で算出されます。

  <StyledMathBox className='katex-box'>
    <BlockMath math='\small\hspace{0.5em}\text{統合使用回数}_{next}=\max\left\{\text{統合使用回数},\hspace{0.5em}\text{クリア時点の使用回数}\right\}\hspace{0.5em}'/>
  </StyledMathBox>

  技ランクの引き継ぎがONであれば、技・術の引き継ぎがOFFでも習得実績のある全ての技・術の統合使用回数が引き継がれます。写し身以外の方法で技・術を再習得すると、引き継がれている使用回数に基づくランクで使用可能になります。ひらめき発生のタイミングでも使用回数は加算されるため、ひらめきとランクアップが同時に発生する場合もあります。
</Box>
