# データの見方
<Box sx={{ minHeight: { xs: `calc(100dvh - 64px - 8px - 50px - 24px - 80px)`, sm: `calc(100dvh - 48px - 8px - 54px - 24px - 80px)` } }}>
  テーブルを構成するデータ系列について説明します。

  <Box sx={{ ml: 1, my: 3 }}>
    ## 名称
    技・術のゲーム内での表示名です。

    同名の技・術が複数存在する場合は名称の最後に連番を付与して区別しています。

    ## カテゴリ
    技・術のカテゴリです。

    使用・習得条件の違いによって武器技、我流技、固有技、ソウル技、ブラッド技、継承技、モンスター技、メカ技、術、敵専用技、支援専用技の11種に分類しています。

    ## 武器タイプ
    技・術と紐づけられている武器タイプです。

    ひらめき処理、対応するスキルの判定、ダメージ計算、ガード・回避の判定で参照されます。

    ## ランクアップ必要回数
    技・術のランクアップ判定に使用される内部値です。

    ランクアップの詳細については <Link to={'/saga-eb/logic/techs-spells-ranking-up/'}>ロジック ＞ 技・術のランクアップ</Link> を参照してください。

    ## 威力
    技・術の威力です。

    ダメージ計算、命中判定で使用されます。プロテクト技では被ダメージの軽減率として使用されます。

    ## BPコスト
    技・術のBPコストです。

    ## 詠唱ターン数
    術の詠唱ターン数です。
