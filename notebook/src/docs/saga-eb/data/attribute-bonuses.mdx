# データの見方

  <Box sx={{ ml: 2, my: 3 }}>
    ## 能力値
    テーブルデータのキーに相当します。

    攻撃ボーナスの場合は筋力、技術力、運動性、体力、知力のいずれかが参照されます。防御ボーナスの場合は体力、集中力のいずれかが参照されます。状態異常ボーナスの場合は技術力、体力、知力、集中力のいずれかが参照されます。

    ## 攻撃ボーナス
    与ダメージに影響する内部値です。

    行動キャラクター自身の能力値を参照してボーナスが決定されます。どの能力値が参照されるか（影響能力）は使用される技・術によって異なります。

    ダメージ計算の詳細については <Link to={'/saga-eb/logic/damage/'}>ロジック ＞ ダメージ計算</Link> を参照してください。

    技・術ごとに設定されている影響能力については <Link to={'/saga-eb/data/ally-techs-spells/'}>データ ＞ 味方の技・術</Link> を参照してください。

    ## 防御ボーナス
    被ダメージに影響する内部値です。

    攻撃対象キャラクターの能力値を参照してボーナスが決定されます。どの能力値が参照されるか（影響能力）は使用される技・術によって異なります。

    ダメージ計算の詳細については <Link to={'/saga-eb/logic/damage/'}>ロジック ＞ ダメージ計算</Link> を参照してください。

    技・術ごとに設定されている影響能力については <Link to={'/saga-eb/data/ally-techs-spells/'}>データ ＞ 味方の技・術</Link> を参照してください。

    ## 状態異常ボーナス
    状態異常の付与と回復の成功率に影響する内部値です。

    付与の場合は行動キャラクター自身と対象キャラクター、回復の場合は状態異常にかかっているキャラクターの能力値を参照してボーナスが決定されます。どの能力値が参照されるか（影響能力）は状態異常によって異なります。
